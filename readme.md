# EduPulse — Student Management System Dashboard

**EduPulse** is a clean, modern, responsive frontend dashboard designed to streamline school and classroom administration. Built using lightweight modern web standards, it features full responsive design alongside instant simulated CRUD database operations.

---

## 🛠️ Project File Architecture

The application runs entirely inside the client environment out of three baseline files:

*   **`index.html`**: Structures the responsive workspace framework, dashboard metrics panels, registration input layout, and the data view table.
*   **`style.css`**: Manages global UI elements using clean CSS custom properties (`--variables`), clean modern typography alignment grids, and adaptive screen breakpoint parameters.
*   **`script.js`**: Drives the transactional dashboard operations, dynamic data rendering, real-time input filtering, and reactive interface stat metrics.

---

## ✨ Features Built-In

1. **Instant Student Registration (Create)**: Submit structural registration inputs to add records to the dashboard engine instantly without page reloads.
2. **Dynamic Live Directory Table (Read)**: View newly loaded student identities instantly indexed with distinct IDs, formatting, and layout tags.
3. **Global Sub-String Searching (Filter)**: An interactive smart search engine bar that filters data rows across Names, IDs, Emails, or Majors as you type.
4. **Targeted Record Eviction (Delete)**: Instantly purge entries out of the current active runtime array using contextual clean actions.
5. **Real-time Stat Aggregators**: Dynamic metric trackers automatically re-calculate registration figures on the fly to mirror data changes.

---

## 🚀 How to Run Locally

Because this system is built entirely as a pure **frontend application framework**, it does not require complex local dev environments or backend server runtimes to evaluate.

1. Download or clone all three repository files (`index.html`, `style.css`, `script.js`).
2. Ensure they are placed **directly next to each other** inside the exact same folder layout.
3. Double-click **`index.html`** or right-click to open it inside any modern desktop web browser (Chrome, Edge, Firefox, or Safari).

---

## 🔒 Runtime Limitation Note
This layout behaves as a **100% frontend template implementation**. The system database is saved inside browser temporary array configurations. Refreshing the browser or closing the window will restore the template dashboard back to its default baseline state.
